# Stashed

Set aside, **not rejected**. These are the Hugo causal-chain scenes. They were taking over
the pool — seven of nine genomes — and canon §4 requires that he arrive late and
recontextualize material the reader has already lived through. That material has to exist
first.

Everything here stays relevant and comes back when there is a book for it to reverse.

| id | title | holds |
|---|---|---|
| G004 | The Second Experiment | run 3; the hope underneath the relief |
| G006 | The Fourth Run | method as penance; run 1 as an unrecoverable accident |
| G007 | The Relief | the sample of one; why there are any further runs |
| G008 | By Morning | the deadline, the uptime he is proud of, the units going in the box |
| G009 | The Arithmetic | he stopped checking; the argument breaks, not the conscience |

Canon §4 and §7 already carry the facts these scenes establish, so nothing is lost by
leaving them here.
